# Personal Portfolio Landing Page (BSL v1.3.3)

## Project Description
A personal portfolio landing page built using static HTML and served via the low-level Bonezegei Scripting Language (BSL v1.3.3) HTTP Web Server framework.

## Tech Stack
- **Language/Framework:** Bonezegei Scripting Language (BSL v1.3.3)
- **Frontend:** HTML5, CSS3
- **Environment:** GitHub Codespaces (Linux x86)

## Setup & Execution Steps
1. Install BSL v1.3.3 on Linux/Codespaces:
   ```bash
   wget [https://github.com/bonezegei/Bonezegei_Scripting_Language/raw/refs/heads/main/Release/Latest/Bonezegei-x86.deb](https://github.com/bonezegei/Bonezegei_Scripting_Language/raw/refs/heads/main/Release/Latest/Bonezegei-x86.deb)
   sudo apt install ./Bonezegei-x86.deb
